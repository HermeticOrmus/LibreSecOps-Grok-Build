# Incident Runbook

Respond calmly; preserve evidence.

## Steps
1. Detect → triage severity → assign owner.
2. Contain (isolate) without destroying forensics.
3. Communicate status to stakeholders.
4. Eradicate cause; recover services.
5. Post-incident: timeline, fixes, follow-ups.
