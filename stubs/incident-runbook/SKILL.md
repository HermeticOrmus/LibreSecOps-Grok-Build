# Incident Runbook

Stub, not a playbook. Real depth: the [`incident-response`](https://github.com/HermeticOrmus/LibreSecOps-Claude-Code/tree/main/plugins/incident-response) plugin from LibreSecOps-Claude-Code. Install it from this marketplace: `grok plugin install incident-response@libre-secops-grok --trust`.

Respond calmly; preserve evidence.

## Steps
1. Detect → triage severity → assign owner.
2. Contain (isolate) without destroying forensics.
3. Communicate status to stakeholders.
4. Eradicate cause; recover services.
5. Post-incident: timeline, fixes, follow-ups.
