# Threat Model Lite

Frame risks without producing attack recipes.

## Steps
1. Name assets and user jobs.
2. Draw trust boundaries (client, edge, app, data).
3. List realistic actors and capabilities (not exploit steps).
4. Map mitigations already in place vs gaps.
5. Rank residual risks; propose hardening controls.
